# Sahil Chaudhary – Telegram Landing Page

A single-page, mobile-first landing page that promotes Sahil Chaudhary's official Telegram channel. It shows a profile card with stats and a 15-second countdown that redirects visitors to Telegram. It also has a "Join Channel" button. Meta Pixel tracks `PageView` on load and `Lead` when a visitor is sent to Telegram.

## Tech
- Plain HTML, CSS and JavaScript (no build step)
- Meta Pixel for ad conversion tracking
- Hosted on Netlify (publishes the `public/` folder)

## Run locally
Open `public/index.html` in a browser, or run `netlify dev --port 8889`.
